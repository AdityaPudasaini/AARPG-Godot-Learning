# AARPG-Godot-Learning

A 2D Action & Adventure RPG project developed using **Godot 4** and **GDScript**.

## Features

* Player movement
* Idle and walking animations
* Player state machine
* Tilemaps and tilesets
* Player attacks
* Hitboxes and hurtboxes
* Health and damage system
* Player stun system
* HUD
* Enemy spawning
* Enemy AI
* Slime enemies
* Camera system and camera limits
* Other RPG gameplay systems

## Built With

* Godot 4
* GDScript
* Pixel Art
